Repositorio de análisis de datos del TFG Sistema de dificultad dinámico adaptativo para videojuegos.

En las primeras pruebas de usuario se encuentran las trazas finales de todos los participantes, los scripts utilizados para procesar los datos y la generación de gráficas y las figuras finales en formato PDF.

En la carpeta de las segundas pruebas de usuario se encuentran las trazas individuales de cada usuario, el script usado para juntarlas todas en un archivo .csv, los scripts utilizados para procesar los datos y la generación de gráficas y las figuras finales en formato PDF.
